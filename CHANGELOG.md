# Changelog

## [1.0.0] - 2026-01-05

### Ajouté
- ✨ Système de fonderie complet avec recettes configurables
- ✨ Système de bijouterie avec taille de pierres et sertissage
- ✨ UI personnalisée en vanilla JavaScript (HTML/CSS/JS)
- ✨ Garage société avec véhicules (Mule, Caracara 2)
- ✨ Système d'exportation/vente d'items
- ✨ Job Fonderie avec 3 grades (Apprenti, Ouvrier, Patron)
- ✨ Support ox_inventory
- ✨ Support ESX Legacy
- ✨ Notifications personnalisées
- ✨ Menu Actions Patron (esx_society)
- ✨ Système de recyclage d'armes confisquées
- ✨ Items pour Hôpitaux (béquilles, fauteuil roulant, gilet pare-balles)
- ✨ Items pour Police (gilet pare-balles)
- ✨ Items pour Gouvernement (gilet pare-balles)
- ✨ Items pour Mécanos (moteurs, turbo, suspension, freins, kit réparation)
- ✨ Bijoux avec différentes pierres précieuses (émeraude, rubis, saphir rose, améthyste, diamant, diamant bleu)
- ✨ Système de permissions par grade pour certaines recettes
- ✨ Animations de crafting
- ✨ Blips configurables sur la carte
- ✨ Markers 3D pour chaque zone

### Technique
- 📦 Configuration centralisée dans config.lua
- 📦 Architecture modulaire (client/server séparés)
- 📦 SQL d'installation complet
- 📦 Documentation complète (README.md)
- 📦 Liste d'items ox_inventory prête à l'emploi
- 📦 Support des véhicules avec clés
- 📦 Compatible LegacyFuel
